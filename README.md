# Degrees of Lewdity - Bunny Transformation Mod

Support Vrelnir and the main game! https://subscribestar.adult/vrelnir https://www.vrelnir.com

The bunny transformation mod adds a bunny TF to the game along with ~~work in progress~~ predator/prey dynamics and other things! Created by winterppeach on tumblr.

Currently there is no BEEESSS sprite support but there is one coming in the future

### Compiling the html

1. On Windows: Run `compile.bat` or `compile-watch.bat`.
2. On Linux: Run `compile.sh`
3. Open `Degrees of Lewdity VERSION.html`.

## How To Get Bunny Transformation?

Currently the only way to get the tf is by picking clovers in the forest and meadows.
